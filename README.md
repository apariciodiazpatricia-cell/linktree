## 🎯 ¿Por qué y para qué he creado este proyecto?

Este proyecto nace como una **alternativa personalizada, moderna y de alto impacto visual** a plataformas comerciales de biografía como *Linktree*, *Bento* o *Bio.link*.

### 💡 Objetivos Clave:
1. **Centralizar mi Identidad Digital**: Proveer un único punto de acceso rápido a mi portfolio profesional, perfiles de código (GitHub), red profesional (LinkedIn), despliegues en vivo (Vercel) y canal directo de contacto.
2. **Identidad Visual Propia**: Reflejar mi pasión por el desarrollo Frontend, el diseño de interfaces interactivas y la estética Cyberpunk / Terminal Hacker, desmarcándome de las plantillas genéricas.
3. **Velocidad y Cero Dependencias**: Maximizar el rendimiento con un tiempo de carga casi instantáneo (100% Vanilla JS, HTML semántico y CSS puro) sin dependencias pesadas de frameworks innecesarios.
4. **Mantenibilidad Ultra Fácil**: Permitir que cualquier desarrollador o reclutador clone el proyecto y configure sus propios enlaces en menos de 1 minuto modificando un único objeto JSON (`CONFIG`).

## 🎨 Estética & Diseño

El proyecto utiliza una paleta de colores cuidadosamente seleccionada para evocar consolas de programación de alta tecnología:

```css
:root {
    --bg-color: #050505;        /* Fondo profundo casi negro */
    --surface-color: #0a0f0a;   /* Superficie de tarjetas y avatar */
    --neon-green: #00ff66;      /* Verde neón brillante característico */
    --neon-green-dim: rgba(0, 255, 102, 0.15); /* Resplandor difuso */
    --text-main: #e0e0e0;       /* Texto principal claro */
    --text-muted: #888888;      /* Texto secundario atenuado */
    --border-color: #1a331a;    /* Bordes sutiles con tono esmeralda */
}
```

* **Tipografías**: `Inter` para legibilidad máxima en títulos y biografías + `JetBrains Mono` para handles, insignias y detalles de código.

## 🚀 Paso a Paso: Cómo Clonar y Ejecutar

Sigue estos sencillos pasos para tener tu propia versión del proyecto funcionando en tu máquina en menos de 2 minutos.

### 1. Requisitos Previos
- Tener instalado **Git** ([Descargar Git](https://git-scm.com/)).
- Un navegador web moderno (Chrome, Edge, Firefox, Brave, Safari).
- *(Opcional)* Editor de código como **VS Code**.

---

### 2. Clonar el Repositorio

Abre tu terminal o PowerShell y ejecuta:

```bash
git clone https://github.com/apariciodiazpatricia-cell/linktree.git
```

---

### 3. Entrar a la Carpeta

```bash
cd linktree
```

---

### 4. Ejecución en Local (4 Métodos)

Puedes abrir y visualizar el proyecto mediante cualquiera de las siguientes opciones:

#### 🔹 Método A: Apertura Directa (El más rápido)
Simplemente haz doble clic sobre el archivo `index.html` o ábrelo directamente desde tu navegador favorito:
- **En Windows**:
  ```powershell
  start index.html
  ```
- **En macOS**:
  ```bash
  open index.html
  ```
- **En Linux**:
  ```bash
  xdg-open index.html
  ```

#### 🔹 Método B: Con VS Code & Extensión Live Server (Recomendado para desarrollo)
1. Abre la carpeta en VS Code:
   ```bash
   code .
   ```
2. Instala la extensión **Live Server** (de *Ritwick Dey*).
3. Haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"** (o pulsa `Alt + L, Alt + O`).

#### 🔹 Método C: Servidor local con Node.js / NPX
Si tienes Node.js instalado:
```bash
npx serve .
```

#### 🔹 Método D: Servidor local con Python
Si tienes Python instalado:
```bash
# Python 3
python -m http.server 8080
```
Luego abre en tu navegador `http://localhost:8080`.

## 🛠️ Guía de Personalización

Toda la información de la página se gestiona desde una única sección al final de [`index.html`](file:///c:/Proyectos/linktree/linktree/index.html).

### Modificar Enlaces y Datos (Objeto CONFIG)

Abre `index.html` y localiza el bloque `<script>`:

```javascript
const CONFIG = {
    name: "Tu Nombre Completo",
    handle: "@tu.usuario",
    bio: "Tu especialidad o biografía corta aquí.",
    avatarText: "IN", // Iniciales para el avatar

    links: [
        {
            title: "Mi Portafolio Web",
            subtitle: "Explora mis proyectos destacados",
            url: "https://tu-portfolio.com",
            icon: "fas fa-laptop-code",
            badge: "Principal"
        },
        {
            title: "GitHub",
            subtitle: "Código y repositorios abiertos",
            url: "https://github.com/tu-usuario",
            icon: "fab fa-github",
            badge: "Código"
        },
        {
            title: "LinkedIn",
            subtitle: "Conectemos en el ámbito profesional",
            url: "https://linkedin.com/in/tu-perfil",
            icon: "fab fa-linkedin-in",
            badge: "Red"
        }
    ]
};
```

---

### Añadir o Quitar Enlaces

Para añadir un nuevo botón, simplemente agrega un nuevo objeto a la lista `links`:

```javascript
{
    title: "Twitter / X",
    subtitle: "Mis reflexiones y actualizaciones diarias",
    url: "https://x.com/tu-cuenta",
    icon: "fab fa-x-twitter",
    badge: "Social"
}
```

> 💡 **Nota de Iconos**: Puedes utilizar cualquier icono de [FontAwesome 6 Icons](https://fontawesome.com/icons) copiando el nombre de la clase (ej. `fas fa-globe`, `fab fa-youtube`, `fas fa-envelope`, etc.).

---

### Cambiar la Paleta de Colores (Variables CSS)

Si deseas cambiar el tema visual, edita las variables en `:root` al inicio de `index.html`:

```css
/* Ejemplo: Tema Cyberpunk Magenta */
:root {
    --bg-color: #080308;
    --surface-color: #120712;
    --neon-green: #ff007f; /* Magenta Neón */
    --neon-green-dim: rgba(255, 0, 127, 0.15);
    --border-color: #380d28;
}

/* Ejemplo: Tema Retro Amber Terminal */
:root {
    --bg-color: #0a0800;
    --surface-color: #141002;
    --neon-green: #ffb000; /* Ámbar Neón */
    --neon-green-dim: rgba(255, 176, 0, 0.15);
    --border-color: #3b2a00;
}
```

## 🌐 Despliegue en Producción

Puedes desplegar este proyecto gratis en cuestión de segundos:

### Opción 1: Vercel (Recomendada)
1. Ve a [Vercel](https://vercel.com/) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** > **"Project"**.
3. Importa el repositorio `linktree`.
4. Deja la configuración por defecto y haz clic en **"Deploy"**.

### Opción 2: GitHub Pages
1. En tu repositorio de GitHub, ve a **Settings** > **Pages**.
2. En la sección **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
3. Haz clic en **Save**. Tu sitio estará disponible en `https://<tu-usuario>.github.io/linktree/`.

### Opción 3: Netlify
1. Arrastra y suelta la carpeta del proyecto en [Netlify Drop](https://app.netlify.com/drop) o conecta el repositorio de GitHub.
